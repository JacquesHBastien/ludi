# Screens

All mockups are 390 x 844 (phone, portrait). File names refer to `design/screens/`.

| # | Screen | File | Notes |
|---|---|---|---|
| 1 | Home | `Home.dc.html` | Mini board logo, "Play on this phone", "Start an online game", "Join with a code", "How to play". |
| 2 | Game setup | `Setup.dc.html` | Players (parish label + editable name + remove), board picker (4 boards, Exclusive badge on St. Croix and Haitian editions), house-rule switches (Two dice default on, Heaven-less default off), "Start the game". |
| 3 | Join with a code | `Join.dc.html` | Code field with "found game" confirmation, name, yard picker (taken yards greyed with player name). v1.1. |
| 4 | Game board | `Main.dc.html` | Header, player strip (active player highlighted), board in frame, turn line + Patois shout, dice tray, hint card, "Up next". Theme prop switches the 4 boards. |
| 4b-d | Board themes | `BoardYardClassic`, `BoardStCroix`, `BoardHaiti` | Same screen in each theme. No Exclusive badge here. |
| 5 | Pass the phone | `Handoff.dc.html` | Full screen, hides the board. Next player's cap, yard name, big name, "Mi ready, mek mi roll". |
| 6 | Big moments | `Moment.dc.html` | One overlay with 4 variants: Kill, Born, Block, Heaven. |
| 7 | Game over | `GameOver.dc.html` | Winner ("Run yard!") with placings, or Heaven-less draw. "Play again", "Back to start". |
| 8 | Rules sheet | `Rules.dc.html` | Bottom sheet over the board. Active settings chips + 6 short rule summaries. |

Not designed yet: online host lobby (share code, see who joined), settings (sound, Patois, large text).
